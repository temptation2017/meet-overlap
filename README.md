# meet-overlap

多时区会议重叠查看器：选几个城市和工作时段，找出大家都能开会的小时。

纯前端、零依赖，打开即用，不上传任何数据。

## 在线演示

https://temptation2017.github.io/meet-overlap/

## 怎么用

1. 打开 [index.html](index.html)，或访问上方 Pages。
2. 从下拉框添加城市（默认已有北京、纽约、伦敦）。
3. 调整统一的工作时段（默认 09–18，结束时刻不含）。
4. 看绿色格子：那一列 UTC 小时里，所有人选中城市都在上班。
5. 下方胶囊列出连续重叠区间（相对第一城本地时间）。

本地直接双击打开即可；也可用任意静态服务器：

```bash
python3 -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 示例

- 北京 + 纽约 + 伦敦，工作日 9–18：通常能看到少数清晨/傍晚重叠小时。
- 只加亚太城市（北京、东京、新加坡）：重叠会明显变长。
- 把结束改成 21，可模拟「愿意晚一点开会」的弹性班。

## 实现说明

- 用 `Intl.DateTimeFormat` + IANA 时区名换算本地小时，自动处理夏令时。
- 以参考日为中心扫前后约 48 个 UTC 小时，避免只看「日历日」漏掉跨日重叠。
- 工作时段按「开始含、结束不含」；支持跨午夜（例如 22–06）。

## 限制

- 所有城市共用同一套「本地工作时段」数字，不能给单城单独设 10–19。
- 预置城市列表有限；未列出的时区需改 `app.js` 里的 `PRESETS`。
- 不处理节假日、午休；只按小时粒度，不做半小时槽。
- 依赖浏览器时区数据库；极老浏览器可能缺部分 IANA 名。

## 后续可改进

- 每城独立工作时段与「愿意弹性 ±N 小时」
- 导出 ICS / 复制「建议开会 UTC 时间」
- 半小时粒度与「最少重叠 N 人」模式
